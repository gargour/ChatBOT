# Project 3: Intelligent Conversational Chatbot with Memory (LangChain & NVIDIA NIM)

## Overview
An interactive web-based chatbot built with Streamlit, LangChain, and NVIDIA NIM (`meta/llama-3.3-70b-instruct`). It features conversational memory to retain context across user interactions within a session.
